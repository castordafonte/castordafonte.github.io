# Imágenes / Images

Esta carpeta contiene todos los recursos gráficos de la página web.

## 📸 Imágenes Requeridas

Coloca aquí las siguientes imágenes:

### Proyectos
- **`project1.jpg`** - Captura del proyecto 1 (Dynamics 365 BC)
  - Tamaño recomendado: 800x600px o similar
  - Formato: JPG, PNG o WebP
  
- **`project2.jpg`** - Captura del proyecto 2 (Power Platform)
  - Tamaño recomendado: 800x600px o similar
  - Formato: JPG, PNG o WebP
  
- **`project3.jpg`** - Captura del proyecto 3 (NAV a BC)
  - Tamaño recomendado: 800x600px o similar
  - Formato: JPG, PNG o WebP

### Currículum
- **`cv.pdf`** - Tu currículum en formato PDF (opcional, también puede ir en la raíz)

## 💡 Consejos

1. **Optimiza las imágenes** antes de subirlas para mejorar la velocidad de carga
2. Usa herramientas como [TinyPNG](https://tinypng.com/) o [Squoosh](https://squoosh.app/)
3. Mantén los nombres de archivo en minúsculas y sin espacios
4. Si no tienes imágenes de proyectos aún, puedes usar placeholders de [Unsplash](https://unsplash.com/) o [Pexels](https://pexels.com/)
